## Overview

A disease prediction system for rice leaves using image classification, built as both a web and an Android project. A sequential neural network trained on six types of rice leaf images reaches almost **90% accuracy**. Results are shown with interactive graphs and charts, along with probable remedies and recommendations for the detected disease.

## What I built

- Image processing and classification models to detect multiple rice leaf diseases.
- Interactive graphs and charts to visualise prediction results.
- Probable remedies and recommendations based on the detected disease.
- A Python Flask web app with HTML, CSS and JavaScript, backed by PostgreSQL.

## Problem

Rice is a staple crop, and leaf diseases reduce yield if they are not identified early. Recognising them usually needs expert knowledge. The goal was to let anyone identify common diseases from a leaf photo — and know what to do next.

## Approach

- Prepared a dataset of rice leaf images across six classes.
- Trained a Keras/TensorFlow **sequential model** in Jupyter Notebook and evaluated its accuracy.
- Served the trained model from Flask and built the result views with charts and remedies.

## Lessons learned

Data quality and balance across classes matter as much as the model itself, and pairing a prediction with practical advice makes a model genuinely useful.

## Future improvements

- Use transfer learning (for example, a pretrained CNN) to improve accuracy.
- Optimise the mobile experience for use in the field.

## Overview

WanderStay is a full-stack clone of Airbnb, built to understand full-stack development in depth. It implements the core stay-search experience — location filtering, a date picker, guest count selection, modal dialogs and shimmer loading — and adds hotel data scraping with automated summaries generated by the **Ollama Llama 2** model.

## What I built

- **Search & filters:** location filtering, date picker and guest count selection.
- **Modal dialogs and shimmer loading** for a smooth, responsive experience.
- **Responsive, interactive frontend** in React.js.
- **Hotel data scraping** with **automated summary generation** using a locally run Llama 2 model via Ollama.

## Architecture

- **Frontend:** React.js.
- **Backend:** Node.js and Express.js REST API.
- **Database:** PostgreSQL.
- **AI:** Ollama running Llama 2 to summarise scraped hotel data.
- **Environment:** Docker on Linux.

## Challenges

- Keeping filter state (location, dates, guests) in sync between the UI and API queries.
- Turning scraped, inconsistent hotel data into clean records a language model could summarise.

## Lessons learned

Rebuilding a familiar product is a fast way to learn the details that make an interface feel polished — and running an LLM locally showed how AI features can be added to an ordinary web app.

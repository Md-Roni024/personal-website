## Overview

An inventory management system covering sales, purchases, authentication, role-based access control and a dashboard.

## What I built

- **Role-based access control** with secure authentication and authorisation using **ASP.NET Core Identity**.
- **Sales and purchase** modules and a management **dashboard**.
- **Database schema** design and optimised queries with **MSSQL and Entity Framework**.
- A responsive UI with HTML, CSS and JavaScript.

## Architecture

- **Backend:** ASP.NET Core (C#) with ASP.NET Core Identity.
- **Data:** MSSQL via Entity Framework.
- **Frontend:** HTML, CSS and JavaScript.
